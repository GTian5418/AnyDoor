环境检查


    

      需要：手机已 Root，已安装 LSPosed / Vector 框架。模块作用域勾选「系统框架 (android)」和「电话 (com.android.phone)」，启用或升级后请完整重启手机。日常开关无需再重启。
    

  






  
关于与用法

  

    

      
任意门是什么

      
一个基于 Xposed 的全局位置模拟工具。它在系统定位服务内部改写每个应用收到的定位，并抹去「模拟位置」标记；同时用测试定位源持续推送坐标，室内没有 GPS 信号也照样有定位。

    

    

      
怎么用

      
    
        
  1. 「环境检查」里确认框架已激活、作用域已配置，首次需重启一次。
    2. 
        
  2. 搜索地点、粘贴坐标或直接点地图，选好位置。
    3. 
        
  3. 点「开始模拟」。任何应用看到的都是这个位置，开关随时切换，无需重启。
    4. 
        
  4. 用方向键 / 悬浮摇杆微调，或用「路线模拟」设起点终点，按步行 / 跑步 / 骑行 / 驾车沿真实道路移动，可同步伪造步数。
    5. 
        
  5. 「隐私加固」一键屏蔽定位环境并伪造设备标识；说明里写清了做不到的部分。
    6. 
      

    

    

      
坐标系说明

      
内部一律使用 WGS-84（GPS 坐标）。高德地图瓦片为 GCJ-02，应用已自动纠偏，所以你在高德底图上点的位置就是应用里看到的位置。从高德/百度网页复制来的坐标，请在设置里选择对应的坐标系再粘贴。

    

    

      
防检测建议

      
保持「屏蔽 WiFi / 基站定位」开启，可避免高德、腾讯等定位 SDK 用周围 WiFi 反推真实位置。随机漂移 2～5 米更像真实 GPS。对特别敏感的应用，可在 LSPosed 里额外把它加进作用域（强化模式）。
